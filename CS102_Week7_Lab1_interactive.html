Part I

Warm-up: the eight Quick checks

no points

One question for each idea of Lecture 6. Write exactly what is printed.

1

Prototype and definition. With void tick() { cout << "* "; }, what does tick(); cout << "x "; tick(); tick(); print?

Defining a function does not run it; every call does.

2

An early return. int sign(int x) { if (x > 0) return 1; if (x < 0) return -1; return 0; }
What does cout << sign(-5) << sign(0) << sign(7); print?

Three calls, each ends at its first return: −1, 0 and 1, printed without spaces.

3

<cmath>. cout << ceil(-2.5) << " " << round(3.5) << " " << fabs(-0.25) << " " << sqrt(2.25);

ceil goes up (towards +∞), so −2.5 → −2. round takes halves away from zero.

4

Conversions at the call. With int half(int x) { return x / 2; } and double halfD(double x) { return x / 2; }: cout << half(7.9) << " " << halfD(7);

7.9 narrows to 7 (the fraction is lost silently), then 7 / 2 = 3. In halfD, 7 widens to 7.0.

5

Scope. int g(int n) { n = n * 2; return n; } and in main: int n = 5; cout << g(n) << " " << n;

g's n is its own copy.

6

Default arguments. int f(int a, int b = 10, int c = 100) { return a + b + c; }
cout << f(1) << " " << f(1, 2) << " " << f(1, 2, 3);

Defaults fill in from the right: 1 + 10 + 100, 1 + 2 + 100, 1 + 2 + 3.

7

By value, by reference. void inc(int& a, int b) { a++; b++; } and in main: int x = 1, y = 1; inc(x, y); inc(x, y); cout << x << " " << y;

a is x itself; b is only a copy of y.

8

Overloading. show(int) prints i, show(double) prints d, show(char) prints c, each followed by a space. show(3); show(3.0); show('3'); show(3 + 0.5);

3 + 0.5 is a double.
